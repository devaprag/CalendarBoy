# CalendarBoy

A proof-of-concept visual calendar. It looks like a normal month view (think Google Calendar), but each event is drawn as a cartoon icon:

| Event type       | Icon                                              |
| ---------------- | ------------------------------------------------- |
| Movie            | Movie camera                                      |
| Overseas holiday | Plane taking off (start day) → dashed flight path → plane landing (end day) |
| Gym              | Dumbbell                                          |
| Shopping         | Shopping bag                                      |
| Call friend      | Phone with speech bubble                          |

## Scope (prototype)
- January 2027 only, with sample events
- No animation
- Fixed event types (no adding new ones)
- Click any icon to see its details

## Run it
Open `index.html` in a browser. It is a single file with no dependencies and no build step.
